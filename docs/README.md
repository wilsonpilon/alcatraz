# Referências temporárias

Esta pasta reúne temporariamente documentos e arquivos usados para estudar
e depurar o jogo original. Os arquivos são referências de seus respectivos
autores e não fazem parte do código original desta recriação.

Segundo o responsável pelo projeto, o proprietário da Editora Aleph autorizou
o uso livre de seus livros. O responsável também confirmou a permissão para
publicar os materiais de terceiros aqui reunidos.

A análise de **Marcelo Silveira / MarMSX** é utilizada somente como
referência para compreender e depurar o jogo original de **Wilson Fazzio
Martins**. Os direitos das demais imagens, traduções e documentos pertencem
a seus respectivos autores.

A listagem `disprosoft.bas` registra a abertura de uma das empresas que
comercializaram o jogo. O responsável pelo projeto confirmou possuir as
permissões necessárias para publicar a listagem e a reprodução da abertura.

As licenças e atribuições específicas serão normalizadas conforme necessário,
em conversa com os autores originais. A licença do código da recriação não
deve ser presumida para os materiais desta pasta.
